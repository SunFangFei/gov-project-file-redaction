# gov-project-file-redaction

面向政府信息化建设方案、可行性研究报告、技术建议书、投资估算表及附件的本地脱敏 Agent Skill。

## 主要能力

- 支持 DOCX、XLSX、PDF。
- 识别并处理项目名称、建设单位、使用单位、供应商、人员、联系方式、网络标识、内部编号等信息。
- 金额支持保留、统一比例缩放、区间化和完全移除。
- 核对数量、单价、合价、小计、总计、核增减额及跨文件金额一致性。
- 检查 Word 修订与批注、Excel 隐藏内容与公式、PDF 底层对象与元数据。
- 输出脱敏文件、受控映射表和风险报告。
- 附带禁止残留词验证脚本。

## 使用

将本仓库安装到支持 Agent Skills（`SKILL.md`）的 Codex、Claude Code 等工具中，然后调用：

```text
使用 $gov-project-file-redaction 对这批方案和投资估算表进行标准脱敏，
金额采用统一比例缩放，并输出脱敏映射表和风险报告。
```

详细规则见 [SKILL.md](SKILL.md)。

> 本仓库不包含任何真实项目资料、金额数据或脱敏映射。
