# DOCX 处理要求

检查正文、所有表格、文本框、形状、页眉页脚、脚注尾注、目录字段、超链接、批注、修订、嵌入对象、自定义 XML 和文档属性。

优先在保持段落、字符样式和表格结构的情况下替换文字。替换跨多个 run 的词语时，应先定位完整段落文本与字符位置，再回写，避免漏掉被 Word 拆分的敏感词。

金额可能出现在正文、表格、图表、文本框和域代码中。采用比例缩放或区间化时，必须同步修改“万元/元”等单位，并与投资估算表逐项复核。

处理修订时必须明确采用哪一种结果：

- 对外版本默认接受所有修订后再脱敏，删除修订作者和时间信息。
- 若用户要求保留修订痕迹，只能交付内部版本，并在风险报告中标明修订可能暴露原文。

删除批注正文、批注作者、缩写和关联标记。清理核心属性与自定义属性中的作者、公司、最后保存者、模板路径及内部文件路径。

验证时重新打开文件；全文搜索禁止残留词；检查目录、分页、表格宽度、图片、编号、字体和金额；必要时渲染为 PDF 或页面图片逐页比对。
