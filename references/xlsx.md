# XLSX 处理要求

检查所有可见与隐藏工作表、单元格值、公式显示值、批注/备注、线程批注、超链接、定义名称、数据验证、图表数据、页眉页脚、打印区域、隐藏行列、外部链接、连接、查询、透视缓存、嵌入对象及工作簿属性。

默认保留工作表顺序、合并单元格、行高列宽、字体边框、数字格式、条件格式、冻结窗格、打印设置和公式。

替换文本时不得把公式改成数值。金额处理后逐项核对：

- 数量×单价与合价；
- 分项小计、分类合计和项目总计；
- 建设方案列、评估报告列和核增减列；
- 折扣率、税率、优惠额与最终金额；
- 方案正文与预算表中的同名功能、数量和金额。

比例缩放应调整输入金额而非破坏 SUM 等汇总公式。若工作簿的合价是公式计算结果，优先修改单价或受控输入；不得同时修改输入和公式结果导致重复缩放。

隐藏内容不是已删除内容。对外文件中不需要的隐藏表、隐藏行列、名称和外部链接应真正移除；需要保留的项目必须列入风险报告。

使用 LibreOffice、Excel 或兼容计算引擎重新计算后再验收。若无法重算，不应声称公式结果已经验证；应列出待用户在 Excel 中打开重算的项目。
